# B2 contract-obligation triage — evaluation pending

CUAD is a US commercial-contract corpus, not evidence about Nigerian or Gulf law. CUAD labels clause categories; Emmanuel must author the additional obligation and deadline annotations under the versioned guide. CUAD category labels are inputs to the agent, so clause location is not evaluated. The contract groups are project-defined title buckets, not an official CUAD family taxonomy. This system is not legal advice.

**No evaluation has been run.** Exception rate, absolute and relative deadline capture, obligation recall and all other metrics are not yet available. The guide and taxonomy are unfilled human-authored skeletons. Human reviews are pending.

Phase 2 provides corpus construction, an annotation desk and review tooling. The dataset, real case labels and API cache are not bundled. See `BUNDLE-NOTES.md` and `annotation/README-annotating.md` for prerequisites. `make test` exercises offline synthetic fixtures; it does not establish performance on CUAD. The CI replay leg cannot pass until the real frozen evaluation artifacts exist.
